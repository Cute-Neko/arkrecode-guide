# Ark Re:Code 角色技能与配装资料库

这是一个面向玩家的静态资料站，用统一页面整理角色的配装面板、六件装备明细、技能理论伤害和技能执行节点。

## 网站内容

- 按中文名或角色编号搜索角色。
- 对照同一角色的多套面板。
- 查看每套面板的属性、装备主副词条、强化分配、套装组成和 Bond。
- 按不同目标防御查看技能理论伤害。
- 查看由 master.db 与已验证战斗节点生成的技能流程说明。

## 内容生成

网站只收录 combined_node_sheets 中由合并生成器产生的页面。人工制作的参考页单独保存在 manual_node_sheets，不会自动进入网站。

运行 website/build_site.py 后，首页会重新扫描已生成的角色合并表并更新角色目录。生成结果是普通静态 HTML，可直接通过 GitHub Pages 发布。
