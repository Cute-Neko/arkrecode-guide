# Ark Re:Code 角色技能与配装资料库

这是一个面向玩家的静态资料站，用统一页面整理角色配装、技能理论伤害与战斗流程。

## 网站功能

- 按中文名或角色编号搜索角色。
- 对照同一角色的多套面板，查看六件装备、主副词条、强化分配、套装组成和 Bond。
- 按 850、1200、1800、2700 四档目标防御查看技能理论伤害。
- 查看由 master.db 与已验证战斗节点生成的角色技能流程。
- 查看纯 PVP 战斗节点表；它移除波次、援军、Boss 和 PVE 奖励分支，并为每个节点列出 master.db 实例或明确的检索结论。
- 查看完整战斗节点图 V9，人工复核同时包含 PVE 与 PVP 的战斗主流程、分支和边。
- 查看基于 GameAssembly.dll 逆向与 master.db 解包数据整理的伤害乘区、三层贯穿和事件结算说明。

## 使用方式

打开首页后可直接搜索角色；顶部的全局资料入口可进入完整节点图和伤害计算说明。网站由普通静态 HTML 构成，可通过 GitHub Pages 浏览。
