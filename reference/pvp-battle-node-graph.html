为什么是“全体 AnyOneBeforeRound → 行动者 BeforeRound”

已核实：T04 包含当前行动者，不是 OthersBeforeRound。 ProcessNowRoleBeforeRound 先对 RoleDataMap 的全部 Value 做 ForEach，再单独调用当前角色的 ProcessBeforeRound。

  1. PVPPunisher / RTAPunisher round-start
  2. T04：全部角色 AnyOneBeforeRound（包含当前行动者）
  3. T05：当前行动者 BeforeRound
  4. T06：持续状态跳动

它和“其他人 → 自己”何时不一样

  • 萝莎莱 H004S2 的 AnyOneBeforeRound 没有 IsNoSelf：轮到萝莎莱时，她仍会作为监听者处理自己的不屈/闪避标记。若改成 OthersBeforeRound，这次自己的监听会被漏掉。
  • Aoi Hinamori H119S2 同时具有 AnyOneBeforeRound 与 BeforeRound：先尝试把后排队友的不屈/吸血标记兑现，再在 Aoi 自己回合对攻击最高敌人施加诅咒。若排除行动者，Aoi 自己回合将不运行前一段被动。
  • 安妮丝朵拉 H202S2 明写 IsNoSelf，只有 1 号位的其他队友开回合才给自己推进 70%。这说明‘排除自己’是数据条件，而不是 AnyOneBeforeRound 的统一语义。

已确认阶段先后；T04 内部来自 RoleDataMap.Values→ToList→ForEach，当前证据没有额外排序，因此不把队伍站位顺序写成已验证规则。
